# Gestion des demandes

Application web Full Stack de gestion et de suivi des demandes, développée dans le cadre d'un test technique.

## 1. Présentation du projet

L'application permet de centraliser la gestion des demandes à travers une interface web intuitive.

### Fonctionnalités principales
- Création d'une demande avec le nom du client et son besoin.
- Consultation des demandes dans un tableau.
- Modification des informations d'une demande.
- Mise à jour du statut : En attente, En cours ou Terminée.
- Filtrage des demandes par statut.
- Affichage de statistiques sur le tableau de bord.

## 2. Technologies utilisées

| Frontend | React, TypeScript, Vite |
| Style | Tailwind CSS |
| Communication API | Axios |
| Backend | PHP, Symfony |
| ORM | Doctrine |
| Base de données | MySQL |
| API | API REST |



## 3. Choix techniques

- **React avec TypeScript :** séparation de l'interface en composants réutilisables et amélioration de la fiabilité du code grâce au typage.
- **Tailwind CSS :** création d'une interface responsive et cohérente.
- **Symfony :** organisation du backend selon une architecture structurée et développement d'une API REST.
- **Doctrine ORM :** simplification des opérations de persistance et de manipulation des données.
- **MySQL :** stockage relationnel des demandes.
- **Axios :** centralisation et simplification des échanges HTTP entre le frontend et le backend.

L'architecture sépare clairement le frontend et le backend afin de faciliter la maintenance et les évolutions futures.
